\section{Lean formalization}\label{app:formalization}

All results in Sections~\ref{sec:deduction}--\ref{sec:foundation} are formalized in Lean~4
(toolchain \texttt{v4.34.1}) in the file \path{lean/WangLogic/Basic.lean} accompanying this
paper. The formalization uses only the core library, contains no \texttt{sorry}, and depends at
most on the axioms \texttt{propext}, \texttt{Quot.sound} and \texttt{Classical.choice}. It builds
with
\begin{center}\texttt{cd lean \&\& lake build}\end{center}
The file \path{lean/ComparatorChallenges/InductionNotDeduction.json} states
\cref{thm:hume} for independent checking with the Comparator tool. \Cref{rem:probability} is not
formalized.
